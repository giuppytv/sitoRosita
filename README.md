# Sito Dietista — Vite + React

## Come avviare il sito sul computer

1. Installa Node.js
2. Apri questa cartella con Visual Studio Code
3. Nel terminale esegui:

```bash
npm install
npm run dev
```

## Dove modificare testi, telefono, email e servizi

Apri:

```text
src/data.js
```

Quasi tutte le cose importanti sono lì:
- nome dottoressa
- numero WhatsApp
- email
- telefono
- servizi
- recensioni
- FAQ
- testi principali

## Come controllare che sia tutto ok

```bash
npm run test
npm run build
```

## Come pubblicarlo in modo professionale

1. Crea un repository su GitHub
2. Carica questi file
3. Vai su Vercel
4. Importa il progetto da GitHub
5. Premi Deploy
6. Collega il dominio professionale
